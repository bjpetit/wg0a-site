Mercury HF Modem

Mercury is a fully open-source HF data modem from Rhizomatica, built as an alternative to closed-source options like VARA. WG0A runs a Winlink RMS gateway mode over Mercury, giving operators an open protocol path for HF Winlink traffic.

What is Mercury?

Mercury is an open-source software modem for digital data communications over HF radio, developed by Rhizomatica. It was created to provide a free, open alternative to proprietary HF modems, with a focus on robust performance over noisy, low-bandwidth HF channels.

Because Mercury is open source, its protocol and code can be inspected, modified, and improved by the community, unlike closed HF modem products.

VARA compatibility

Mercury exposes a VARA-compatible TCP TNC interface, so Winlink programs that already know how to drive a VARA modem can drive Mercury the same way, with no protocol changes on the Winlink side. For Winlink Express or Pat Winlink clients, you would point the VARA configuration at Mercury's address and ports, just like you would for a VARA modem.

Port Purpose
8300 (base port) Control port — VARA-style text commands (MYCALL, LISTEN, CONNECT, BW2750, etc.) and status lines.
8301 (base port + 1) Data port — raw application payload for a connected session.

In practice, this means Winlink Express (or another Winlink client) can be configured with a VARA HF session pointed at Mercury's control/data ports (typically 127.0.0.1:8300 / 8301) exactly as it would for the real VARA modem software, and Mercury handles the RF side transparently.

Mercury also emits VARA-style asynchronous status lines such as BUSY ON/BUSY OFF, PENDING, and CONNECTED, which is what lets existing VARA-aware hosts like Winlink Express and BPQ32 hold off transmitting and react to link state without any special-casing for Mercury.
